Install in a minute

Orbcast isn’t notarized by Apple yet, so macOS asks you to confirm the first time.

1. Install

  1. Download Orbcast.dmg and open it, or build it from source.
  2. Drag Orbcast into Applications.
  3. Open Orbcast from Applications.

2. If macOS blocks it

  1. Click Done on the warning.
  2. Open System Settings › Privacy & Security.
  3. Scroll down and click Open Anyway next to Orbcast, then confirm.

3. Allow permissions

  1. Allow Camera and Microphone when asked.
  2. Turn on Orbcast in Screen & System Audio Recording.
  3. Click Relaunch in Orbcast’s welcome window.

4. Record

  1. Press ⌥⌘R or click Start Recording.
  2. Press ⌥⌘R again to stop.
  3. Trim, export MP4, share.
